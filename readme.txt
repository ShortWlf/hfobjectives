"HF Objectives is a dynamic Minecraft mod that brings a fresh layer of excitement to your gameplay with customizable objectives. Whether it’s gathering resources, eliminating mobs, or surviving unique challenges like standing on a gold block without taking damage, this mod keeps players engaged and on their toes. Designed with flexibility and fun in mind, HF Objectives allows server admins to tailor tasks and create immersive experiences for players."

Version 1.0.0

Initial release of HF Objectives!

Added customizable objectives, including:

Gather: Collect items like dirt, stone, or arrows.

Mob Kill: Defeat specific mobs like zombies.

Don’t Get Hit: Survive for a set duration without taking damage.

Stand: Stay on specific blocks for a required amount of time.

Integrated /startobjective, /completeobjective, /randobj, and /hfreloadobjectives commands for seamless gameplay interaction.

Real-time objective tracking with action bar updates.

Configurable settings for objective types, time limits, and text colors.
